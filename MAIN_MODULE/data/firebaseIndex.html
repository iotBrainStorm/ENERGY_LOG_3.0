🔥 Firebase Setup

Configure your Firebase Realtime Database

📝 Instructions:
1. Go to Firebase Console → Database → Realtime Database
2. Copy your database URL (ends with .firebaseio.com)
3. Get your auth token from Project Settings → Service accounts
Example: https://my-project-12345.firebaseio.com
Get from: Project Settings → Service accounts → Database secrets
Paste your Firebase security rules JSON (optional)
